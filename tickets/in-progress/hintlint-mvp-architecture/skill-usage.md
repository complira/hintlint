# Skill Usage

## Skills Applied

### software-engineering-workflow-skill

Used for:

- staged planning,
- artifact creation,
- implementation gate tracking,
- acceptance checks,
- code-review/handoff discipline.

This is the primary skill for the M0 implementation.

### Local `scientist`

Source: `.codex/skills/scientist/SKILL.md`

Used for:

- competitor teardown claim discipline,
- benchmark/differentiation framing,
- avoiding unsupported uniqueness claims,
- separating evidence-backed findings from heuristic or methodology claims.

Scientist verdict for M0 claims:

- Pass with constraints.

M0 can claim:

- local CLI scaffold exists,
- fixtures run,
- supported TypeScript/Python patterns extract tool metadata,
- built-in MVP detector produces fixture-backed source-pattern findings,
- competitor/methodology positioning is documented.

M0 must not claim:

- production security scanner,
- complete MCP vulnerability detection,
- Semgrep/dataflow proof,
- ML-backed behavior verification,
- broad ecosystem benchmark superiority.
